# RompeLadrillos — historical project

The original Java Swing source is available in the historical [master revision](https://github.com/lucianoLattante/rompeLadrillos/tree/bebba4a15d76f542569c45a09796a3e6ee547587/src). It contains `Main.java`, `GamePlay.java`, and `MapGenerator.java`. The default branch retains the historical record.

All three source files compiled together with JDK 8 (1.8.0_202), with annotation processing disabled. The checked-in binaries were excluded from verification. Interactive gameplay and packaging are outside this source check.

## Resumen en español

El código Java original se recuperó de la rama histórica `master`. La compilación se hizo desde los tres archivos fuente. El repositorio se conserva como antecedente de aprendizaje.
